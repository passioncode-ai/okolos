# okolos-extension — документация

Браузерная защита для эпохи AI-агентов: находит на страницах скрытые инструкции,
подсунутые твоему AI, проверяет ссылки и загрузки, следит за расширениями и
утёкшими паролями, а дружелюбный ассистент доводит до починки. Всё считается
локально — **история браузинга не покидает устройство**.

**REQ-37 закрыт решением, а не отложен.** Политика по весам принята и записана
в [licences.md](licences.md): проект несёт только те веса, которые можно
перераспространять без принятия пользователем чужих условий. Инженерная часть
измерена 2026-08-08 и остановилась раньше квантизации, потому что квантовать
нечего. Единственный ungated Apache-2.0 артефакт (738 563 308 байт, sha256
сошёлся) прогнан по корпусу: задержка **7 мс** при бюджете 250 — не ограничение;
ограничением оказались **ложные срабатывания 9 из 34 при уверенности 0.97–1.00**
на подписях для скринридеров в обоих языках. Модель обучена на промптах, а
подпись кнопки — повелительная фраза: «Закрыть уведомление» = 1.000. Правила
первой ступени на том же корпусе дают 100% recall при нуле ложных, поэтому
третья ступень не выпускается, а честная деградация уже построена и покрыта
тестами. Измеритель — `tools/model/evaluate.py`; файл весов, попавший в дерево
без записи в `licences.md`, валит сборку.

**История изменений:** [CHANGELOG.md](../CHANGELOG.md) — то, что видит
пользователь, а не выгрузка коммитов. Пока ничего не выпущено, и он это говорит.

**Как здесь работать:** [runbooks/development.md](runbooks/development.md) —
поднять, собрать, прогнать, выпустить. Команды в нём исполнимы как записаны, и
это проверено гейтом в обе стороны: команда без скрипта и скрипт без строчки в
раннбуке одинаково валят сборку.

**Принятые решения:** [adr/](adr/) — девятнадцать развилок, на которых продукт мог пойти
иначе: закрытый shadow-корень, воркер, который не подписывает, третья ступень,
которой нет. У каждой записана цена и механизм, который её держит; запись,
называющая несуществующий файл, валит сборку.

**Приватность:** [privacy.md](privacy.md) — что уходит с устройства, куда и
насколько; страница живёт по адресу
[/privacy](https://okolos-proxy.sergeysheleg4.workers.dev/privacy) и сверяется с
кодом тестами: назначения читаются из контракта, адресаты — из исходников
расширения, сроки — из схемы хранилища.

**Выпуск:** `pnpm package` собирает, проверяет и кладёт архив в
`apps/extension/dist/release`, печатая размер и sha256. Отказывается паковать
сборку с тестовыми хуками (в ней открыты shadow-корни), манифест, называющий
отсутствующий файл, и локаль, не отвечающую на `__MSG__` из манифеста. CI гоняет
те же проверки на каждый push — до загрузки, а не после.

**Что стоит между работающим продуктом и выпущенным** —
[бэклог](superpowers/backlog.md). Четыре причины, стоявшие здесь до 2026-09-11 —
отсутствие локализации, иконок, политики приватности и упаковки — закрыты ещё
2026-08-08/09 (B-01…B-05), а строка о них пережила их на месяц: ровно тот дрейф,
который этот раздел заводился ловить. Сегодняшние: **фид блокировки просрочен**
(29.3 дня при потолке 14, то есть функция блокировки работает вхолостую),
**вершина красная на CI** с 2026-08-21, и **ключ HIBP негде ввести**, отчего
половина проверки утечек недостижима. Ни одна из причин не про детекторы.

**REQ-25 закрыт 2026-08-07:** воркер выкачен, D1 создана, схема накатана, cron
зарегистрирован, смоук из четырёх проверок ходит по живому адресу — раннбук
[runbooks/worker-deploy.md](runbooks/worker-deploy.md). **Ключ подписи фидов**
сгенерирован тем же днём: публичная половина вкомпилирована, приватная живёт вне
репозитория, и гейт проверяет содержимое каждого отслеживаемого файла на
PEM-заголовок — [runbooks/feed-signing.md](runbooks/feed-signing.md).

## Карта кода

Ядро отделено от браузера намеренно: пакеты `core-*` не имеют права трогать
браузерные API, сеть, часы и случайность. Это не соглашение, а два независимых
гейта — правило ESLint по исходнику и скан собранных бандлов (`tools/gates/`).
Поэтому детекторы одинаковы в Chrome и Firefox, а их тесты не требуют браузера.

| Пакет | Что решает |
|---|---|
| `contracts` | словарь, который знают все слои: вердикт, улика, RPC, гейт-решение. Ничего не импортирует |
| `core-mail` | письмо: разбор `.eml`/`.emlx`, вердикт из отработавших проверок, блок «не проверялось» |
| `core-injection` | скрытые инструкции: 9 детерминированных сигналов на двух уровнях ([ADR-0012](adr/0012-one-signal-is-a-suspicion.md)) + ступень классификатора; `chars.ts` решает, что невидимый символ делает, а не только что он есть |
| `core-sanitizer` | какие узлы снимать (только по проверяемым уликам) |
| `core-gate` | пускать ли действие агента; дефолт — Block |
| `core-queue` | ранжирование и «не больше трёх», и дифф «что изменилось» |
| `core-feeds` | проверка подписи, дельты, откат, правила блокировки |
| `core-lookalike` | punycode, гомоглифы, опечаточные домены |
| `core-traps` | ClickFix и tech-support ловушки |
| `core-credential` | пауза перед паролем и k-anon-проверка |
| `core-download` | вердикт по загрузке из реально отработавших проверок |
| `core-leaks` | слияние источников утечек с честным покрытием |
| `core-recovery` | чеклисты восстановления, по убыванию ущерба |
| `i18n` | каталог сообщений и резолвер к нему; локаль приходит от хоста, не из глобала |
| `core-extensions` | дельты разрешений, смена издателя, разбор пакета |
| `platform` | единственное место, где живёт разница Chrome/Firefox |
| `net` | единственная точка выхода в сеть; аудит пишется **до** отправки |
| `storage` | IndexedDB v3, ретеншен, экспорт и стирание |
| `model` | доставка весов и сессия ONNX |
| `ui` | поверхности расширения; в странице живут в закрытом shadow root. Сколько их — считает [ux/screens.md](ux/screens.md), а не эта строка |

| Приложение | Что это |
|---|---|
| `apps/extension` | само расширение: content script, service worker, страницы |
| `apps/proxy` | тонкий Cloudflare Worker: фиды, статус домена, апелляции |
| `apps/mail-cli` | команда `okolos-mail scan <файл>`: проверка одного письма на этой машине |

## Процесс

Путь пройден целиком: брейншторм → [спека](superpowers/specs/) →
[план](superpowers/plans/) → UX-цепочка → реализация по TDD → гейты →
[приёмка](superpowers/audits/2026-08-05-acceptance.md).

Что осталось в силе на будущее: **любое изменение user-facing поведения
обновляет `docs/ux/` тем же изменением**, а `python3 docs/ux/lint.py` это
проверяет. Разбор каждой ошибки, найденной за прогон, — в
[retro.md](superpowers/retro.md); там же 8 постоянных инструкций, выведенных из
них.
