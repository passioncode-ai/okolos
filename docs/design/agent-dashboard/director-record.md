# Запись режиссёра: страница Okolos Agent (SCR-23, SCR-24)

surface_class: product

## Brief

Страница локального демона Okolos Agent: человек сверяет код и подтверждает привязку агента (SCR-23),
видит открытые задачи агентов и их отказы (SCR-24). Открывается только в Fabric Dashboards, в узкой
панели от 360 CSS px. Прогон: [бриф Б1](../../superpowers/specs/2026-10-27-bridge-b1-brief.md).

## Mode

declined: визуальных решений этот прогон не принимает. Вид страницы задают два уже закреплённых
источника. Первый: набор дашборда Fabric (`fabric-dashboard/0.1`), обязательный для страницы в Fabric
Dashboards: он следует теме и схеме хоста (семь тем AA, светлая и тёмная). Второй: стиль Okolos из
`docs/ux/screens.md` → Design system (плотный UI, без анимации, серьёзность словом и цветом, один
`h1`, одна панель на экран). Новой палитры, шрифта или движения не вводится, значит направлять нечего.

## References

- `docs/ux/screens.md` → Design system: стиль Okolos.
- Скил `fabric-agent-adapter:building-fabric-services` → `references/dashboard-kit.md`: разметка и темы.

## Markers

- Код привязки крупный, моноширинный, по три цифры.
- Имя агента подписано как имя, которое агент дал себе сам.
- Подтвердить и Отказать одного веса, рядом. Отказ не прячется.

## Open

Ничего: страница наследует вид и не открывает визуальных вопросов.
