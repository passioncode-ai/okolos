# Бренд-пак Okolos

Contract: brand-contract v1

Три файла и один линтер. [voice.md](voice.md) — голос и пять правил,
[terminology.md](terminology.md) — одно понятие один термин на каждом языке,
[facts.md](facts.md) — что о продукте можно утверждать и чем это проверяется.
`pnpm brand:lint` (это `docs/brand/lint.py` через тот Python 3, что есть на машине)
проверяет пак против контракта; он подключён к
`pnpm gates`, к `.githooks/pre-push` и к CI, и ошибка в нём отказывает в пуше.

## Что линтер читает

Он не угадывает, где проект держит текст: без блока ниже он молчал бы о
поверхностях, которых никогда не открывал, а чистый отчёт о непрочитанном — хуже
отсутствия отчёта.

Sources:
    store: docs/store/listing.md

## Чего в блоке нет, и почему

Ключ, которого нет, — это проверки, которые **не выполнялись**. Линтер их не
считает (его собственная строка «counted as skipped» — обещание, которого в коде
нет), поэтому счёт держит этот файл:

| Ключ | Не объявлен, потому что |
|---|---|
| `ui` | строки интерфейса живут в `apps/extension/_locales/*/messages.json`, а линтер читает документы с front matter и телом. Их сходимость с `terminology.md` держит `tools/docs.test.ts`, а не этот линтер. |
| `marketing` | единственная публичная страница-текст — лендинг, и он собран в `apps/proxy/src/router.ts`. Указать сюда `.ts` значит скормить проверке «каждое число из тела есть в facts.md» каждый числовой литерал TypeScript. |
| `robots` | `robots.txt` в проекте нет: индексацию запрещает `<meta name="robots" content="noindex">` (`apps/proxy/src/router.ts:785`), а эту форму проверка B050 не читает. |
| `locales` | проверка паритета берёт код языка из **имени файла** (`path.stem`), а у нас все каталоги называются `messages.json` — объявить ключ значит сравнить `messages` с `messages` и получить 100% на любом состоянии. |

Каждая строка здесь — не отговорка, а адрес: пока проверка не выполняется,
названо, кто выполняет её вместо неё, либо что именно мешает.
