# Развилки — решены

Все семь закрыты в брейншторме и на intake-грилле пайплайна 2026-08-04.
Канонический источник решений:
[superpowers/briefs/2026-08-04-okolos-p0-p5.md](superpowers/briefs/2026-08-04-okolos-p0-p5.md) §3.
Файл сохранён, чтобы ссылки не ломались и был виден путь рассуждения.

| # | Развилка | Решение | Где зафиксировано |
|---|---|---|---|
| Q1 | Форма продукта | Расширение + **тонкий прокси-воркер** на Cloudflare. Полностью автономный вариант отпал: публичная страница статуса домена и апелляции (SCR-14, REQ-25/26) требует серверной стороны | брифинг D-7, product-vision §4 |
| Q2 | Аудитория и монетизация | **Код открыт, пользоваться бесплатно**: лицензия организации — PolyForm Noncommercial или Internal Use, коммерческая по запросу (ADR-0015, 2026-09-29). Монетизации нет — записано в `ux/foundation.md` → Monetization, поэтому пейволов, триалов и flow отмены подписки в цепочке не существует | брифинг D-8 |
| Q3 | Бюджет на платные фиды | **Нулевой на старте.** Pwned Passwords офлайн, HIBP-метаданные, XposedOrNot, Hudson Rock Community, все URL-фиды, CertStream и NRD — бесплатны. Платные подключаются точечно как «глубокая проверка по требованию» | data-sources §1 |
| Q4 | Коммерческий статус и Safe Browsing | Non-commercial сохраняется → **Safe Browsing v5 и VirusTotal public API остаются бесплатными**. Источники заворачиваются в сменный интерфейс: переход на Web Risk не потребует переписывания логики | data-sources §3, §7.4 |
| Q5 | Браузеры | **Chrome + Edge + Firefox.** Ядро браузеро-независимо, различия (у Firefox сохранён блокирующий `webRequest`, DNR урезан, Gemini Nano отсутствует) поглощаются адаптерами в `platform/` | REQ-27 |
| Q6 | Почта | **Отложена.** Gmail OAuth в простом исполнении противоречит принципу P1; IMAP — отдельная веха | carry-over ledger |
| Q7 | Хранилище индекса | **Локальное** (IndexedDB). Без шифрования-театра: ключ рядом с данными ничего не защищает, а выглядит защитой. Способ поставки корпуса паролей (полный дамп против k-anon) решается замером в спеке | design §4, REQ-20 |
