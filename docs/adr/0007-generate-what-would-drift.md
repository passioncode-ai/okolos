# 0007. Всё, что иначе разойдётся, — генерируется

Принято постепенно, закреплено 2026-08-08. Действует.

## Контекст

Один и тот же факт, записанный дважды, — это два факта в день, когда меняется
один из них. Проект наступил на это несколько раз: вайрфрейм, который никто не
перерисовал; политика приватности, которую пришлось бы править в двух местах;
двадцать два хекса в оверлеях рядом с палитрой токенов.

## Решение

Есть один источник, из него генерируется представление, и **тест сверяет
закоммиченный результат с тем, что даёт генератор**.

| Что | Источник | Генератор |
|---|---|---|
| Вайрфреймы экранов | рендереры | `tools/wireframes.mjs` |
| Иконки, знак в SVG, набор Okolos Bridge, промо-плитка магазина | описание в коде (`GEOMETRY`) | `tools/icons.mjs` |
| CSS-токены | `packages/ui/src/tokens.ts` | `tools/tokens.mjs` |
| Страница приватности | `docs/privacy.md` | `tools/privacy-page.mjs` |

## Цена

Генератор — ещё один файл, который надо запускать. Поэтому каждый из них
проверяется тестом с внятным сообщением: «отличается от источника — запусти
`node tools/...`». Это дешевле, чем расхождение, которое никто не заметил.

## Чем держится

По тесту на каждый генератор, и все они подтверждены подсадкой: изменить
источник и не пересобрать — красный. Ровно это и случилось при правке политики
приватности в тот же день: гейт поймал.

**Дополнено 2026-10-05.** Знак перешёл на плитку продуктов PassionCode.ai, и
генератор стал выдавать не только иконки расширения, но и SVG-исходник знака,
знак Okolos Bridge и промо-плитку — всё из одного описания. Иконки в манифестах
сверяет `tools/manifest.test.ts`, остальное — `tools/icons.test.ts`; он же
проверяет по пикселям, что кольцо замкнуто на каждом размере.

**Дополнено 2026-10-06.** Кольцо сменилось щитом (решение оператора: знак не должен
повторять Observatory). Описание то же — `GEOMETRY`, центральная линия щита одна для SVG и
растра (`centreline()`), — и тест по пикселям теперь проверяет замкнутость контура щита.
