# ADR-0015. Okolos — под лицензией организации

**Дата:** 2026-09-29
**Статус:** принято оператором 2026-09-29 («делаем, что можно пользоваться
организацией без согласия… требуем, что коммерческое использование нужно
согласовать», адрес — PassionCode)
**Заменяет:** [ADR-0014](0014-the-engine-is-permissive-the-product-is-copyleft.md)
(Apache-2.0 для движка, AGPL-3.0 для продукта), принятый в тот же день и не
доживший до выпуска.

## Контекст

У каждого публичного инструмента PassionCode.ai одинаковые условия:
Observatory, Dashboards, Switchboard и `fabric-agent-adapter` выходят под
`PolyForm-Noncommercial-1.0.0 OR LicenseRef-PolyForm-Internal-Use-1.0.0`, с CLA
и коммерческой лицензией через contact@passioncode.ai (`org-index/RULES.md` §9).
Проверено по `LICENSE` и `package.json` каждого публичного репозитория
организации 2026-09-29. Okolos был единственным публичным продуктом не на этой
схеме.

Оператор задал цель:
- код открыт;
- человек пользуется и меняет его бесплатно;
- организация пользуется у себя без согласия;
- коммерческое использование согласуется.

Ни AGPL, ни Apache этого не дают: обе лицензии разрешают продавать продукт на
основе кода, не спрашивая автора. Ровно эту цель описывает схема организации:
- Noncommercial — для людей и некоммерческих организаций;
- Internal Use — для внутренней работы любой компании;
- всё остальное — по отдельной лицензии.

Сменить лицензию можно без чужого согласия: у кода нет других авторов, кроме
оператора (обоснование в ADR-0014).

## Решение

**Весь репозиторий — под выражением организации**, с тем же `LICENSE`, что у
Observatory, и тем же [CLA.md](../../CLA.md). Коммерческая лицензия — через
contact@passioncode.ai.

- **Разделения на движок и продукт больше нет.** Встраивать движок в Fabric Inbox
  это не мешает, потому что лицензиар у обоих один. А стороннему продукту для
  встраивания как раз и нужна коммерческая лицензия. Это и есть цель, а не
  побочный эффект.
- **История сохранена.** Коммиты до `5a8e490` включительно остаются под теми
  лицензиями, под которыми вышли (AGPL-3.0, в последнем — Apache-2.0 для
  движка). Так записано в `LICENSE`, как Observatory записал свою MIT-историю.
- **Чужое остаётся под своими условиями.** Выборка Public Suffix List — MPL-2.0,
  данные OpenPhish — условия источника, данные HIBP — CC BY 4.0 с атрибуцией на
  экране.
- **Зависимости** — только с разрешительной лицензией. Копилефтная зависимость
  сделала бы наши условия нераспространяемыми.

## Цена

- **Это не open source по определению OSI**, и так его называть нельзя. Ни в
  магазине, ни на лендинге, ни в README слов «open source» нет. Там стоит
  «исходный код открыт» или «source-available».
- **Стороннему разработчику агентов** движок бесплатно не достаётся: встраивание
  в продукт для других требует коммерческой лицензии. Сегмент «разработчики» из
  вижена §5 начинается с письма на contact@passioncode.ai.
- **Контрибьюторы, пришедшие ради AGPL,** получают другие условия. Внешних
  контрибьюторов на дату решения нет.
