# ADR-0014. Движок — разрешительный, продукт — копилефт

**Дата:** 2026-09-29
**Статус:** заменено [ADR-0015](0015-okolos-takes-the-organisations-licence.md) в тот же день;
принято оператором 2026-09-29 («Лицензия Apache 2.0 для движка. AGPL
— расширение, агент»)
**Отменяет:** «весь проект под AGPL-3.0-only» из Q2
([product-vision.md](../product-vision.md), [open-questions.md](../open-questions.md)).
Остальная часть Q2 — бесплатно, без подписок и монетизации — остаётся в силе.

## Контекст

Стратегия экосистемы ([strategy/2026-09-29-ecosystem.md](../strategy/2026-09-29-ecosystem.md))
предлагает встроить детекторы Okolos туда, где их читают агенты. Первым
кандидатом стоит Worker Fabric Inbox: он распространяется под Apache-2.0 и
работает в аккаунте пользователя. AGPL-движок нельзя слинковать в такой Worker,
не распространив AGPL на сам Inbox. То же относится к любому стороннему агенту.

Лицензия всего репозитория — AGPL-3.0-only — выбиралась под расширение, чтобы
размещённый форк был обязан открыть код. Для расширения, воркера и будущего
агента этот довод остаётся верным. Для движка он работает против цели: движок
нужен как раз для того, чтобы его встраивали.

Сменить лицензию можно без чужого согласия. `git shortlog -sne HEAD` на
2026-09-29 показывает три идентичности авторов: два адреса оператора и агента на
его машине. Других авторов у кода нет.

## Решение

| Часть | Лицензия |
|---|---|
| `packages/contracts` и каждый `packages/core-*` — движок | Apache-2.0 |
| `corpora/` | Apache-2.0 |
| `packages/core-lookalike/src/suffixes.json` — выборка из Public Suffix List | MPL-2.0 (своя лицензия источника) |
| Всё остальное: `apps/*`, `packages/{i18n,model,net,platform,storage,ui}`, инструменты, документация, будущий локальный агент | AGPL-3.0-only |

Граница движка совпадает с правилом чистоты REQ-01 (`eslint.config.js:102`): в
`core-*` уже запрещены браузер, сеть и часы. Значит, «то, что можно встроить» и
«то, что под Apache» — одно и то же множество, и проводить его заново не нужно.

**Зависимость только в одну сторону:** движок не импортирует код продукта. Иначе
Apache на пакете стал бы ярлыком, под которым лежит AGPL.

Использование бесплатно для человека и для организации: подписок, платных
уровней и ключей нет. Вклад принимается по [CLA.md](../../CLA.md) — тому же
договору, что во всей организации PassionCode.ai.

## Цена

- **Закрытый форк движка разрешён.** Кто-то может встроить правила в платный
  продукт и не вернуть улучшения. Принято сознательно: ценность Okolos не в
  тексте правил, который и так публичен, а в корпусах, фидах и интеграциях.
- **Два текста лицензии в одном дереве.** Корневой `LICENSE` остаётся AGPL, у
  каждого пакета движка свои `LICENSE` и `NOTICE`. Читателю нужна карта — она
  в [LICENSING.md](../../LICENSING.md).
- **Расходится с RULES §9 организации.** Публичные инструменты PassionCode.ai
  выходят под PolyForm (source-available). Okolos остаётся открытым. Строка об
  этом в `org-index/RULES.md` — изменение организации, и оно вносится с согласия
  оператора отдельным PR.
