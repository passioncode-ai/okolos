# ADR-0021. Данные об использовании и ошибках: включены по умолчанию, выключаются в настройках

**Дата:** 2026-11-05
**Статус:** принято. Решение оператора 2026-11-04 для всех продуктов PassionCode (пункты C и D,
ретрансляция fabric-workspace-f1 из сессии fabric-32), ответ оператора 2026-11-04 около 17:25 UTC:
«На все остальное там апрув, типа давай делать», исключения для Okolos нет.
**Основание:** строки B-198 и B-199 в `docs/backlog.md`; журнал прогона
`.task-pipeline/run-usage-analytics.md` на ветке `feat/usage-analytics`.

## Контекст

До этой записи `docs/privacy.md` обещал «Нет аналитики. Ни счётчиков, ни идентификатора установки,
ни отчётов об ошибках». Сбои у людей нам не были видны вовсе. Оператор решил: продукт при первом
запуске говорит, что отправляет данные об использовании и ошибках, только чтобы его улучшать; сбор
включён по умолчанию, в том числе у уже установленных копий; выключается в настройках каждого
продукта. У Okolos установленных копий из магазина ещё нет: первый выпуск в магазине и есть первая
сборка, которая отправляет, и уведомление первого запуска видит каждый, у кого сбор включён.

## Решение

- Назначение `usage-data` в единственной точке выхода (ADR-0003), один хост
  `analytics.passioncode.ai` (Aptabase организации). Запись в журнал
  отправок до запроса, как у всех назначений.
- Закрытый каталог событий: `apps/extension/src/background/usage/catalogue.ts` и `docs/analytics.md`,
  которые тест держит равными. Каждое свойство принимает только значения из списка, поэтому ни адрес
  страницы, ни её текст, ни имя файла, ни почта, ни пароль не могут попасть в событие (ADR-0019).
- К событию приёмник добавляет `iid` (случайный номер установки, пока сбор включён), `environment` и
  `platform: browser_extension`. Выключение удаляет номер и неотправленную очередь; повторное
  включение даёт новый номер.
- ОС расширение не читает: события идут по одному на маршрут одиночных событий с пустым `osName`, и
  систему с браузером сервер определяет по заголовку запроса. Обещание «кода, зависящего от ОС, нет»
  (B-166) остаётся верным, а его гейт сужен ровно на две записи: значение `platform:"browser_extension"`
  и `appVersion:` от версии самого расширения; чтение `navigator.platform` и `navigator.appVersion`
  его по-прежнему валит.
- Chrome и Edge: включено с первого запуска, уведомление на экране первого запуска. Firefox 140+:
  `data_collection_permissions.optional: [technicalAndInteraction]`, выбор хранит браузер. Firefox
  129–139: встроенного согласия нет, ничего не отправляется; порог 129 сохранён.
- Отправка вместе с будильником фида, раз в 6 часов (Chrome и Edge, закрытые в срок будильника, запускают
  его один раз при старте; Firefox не проверен, B-211), не больше 25 событий за раз, то есть
  не больше 100 в сутки; события старше суток отбрасываются, очередь не больше 500. Повтор только на 408,
  429, 5xx, ошибку сети и сбой записи в журнал отправок. Изменения состояния идут по одному (`start.ts`): иначе выключение посреди
  записи события возвращало старый номер.
  Четвёртого будильника нет, бюджет пробуждения (`wake.ts`) не изменился.
- Ключ приложения есть только в архиве для магазина, из хранилища и только на время `pnpm package`;
  после архива команда пересобирает `dist/<target>` без ключа, а при сбое удаляет сборку с ключом.
- «Удалить все данные» заменяет номер установки и очищает очередь.

## Связь с ADR-0019

ADR-0019 в «Цене» пишет, что обещание продукта теперь читается «ничего не уходит к нам». После этой
записи верно уже «ничего из содержимого страниц не уходит к нам»: данные об использовании и ошибках
уходят на `analytics.passioncode.ai`, и в них нет ни адреса страницы, ни её текста.

## Цена

- Продукт, который обещал «нет аналитики», теперь отправляет события. Обещание переписано в
  `docs/privacy.md` и в карточке магазина в том же изменении.
- Слово «анонимно» в интерфейсе не используется: бренд-пак запрещает его как обещание
  (`docs/brand/terminology.md`), тексты называют, что уходит и чего там нет.
- Удаление уже отправленных событий расширение не делает и не обещает.

## Чем держится

- `packages/net/src/destinations.test.ts`: назначение `usage-data` достаёт только до
  `analytics.passioncode.ai` и пишет журнал до запроса.
- `apps/extension/src/background/usage/sink.test.ts`: выключенный сбор ничего не отправляет и удаляет
  номер установки; каталог отказывает любому значению вне списка, в том числе подложенным адресу,
  тексту, имени файла, почте и паролю; `iid`, `environment`, `platform` на каждом событии.
- `apps/extension/src/background/usage/consent.test.ts`, `start.test.ts`: правила Chrome, Firefox 140+
  и Firefox 129–139.
- `tools/analytics.test.ts`: `docs/analytics.md` равен каталогу в коде; ключа приложения нет ни в
  отслеживаемых файлах, ни в сборках вне архива для магазина.
- `tools/docs.test.ts`: `docs/privacy.md` и `docs/brand/facts.md` называют назначение и его хост;
  обещание «расширение не спрашивает ОС» читается из собранного кода.
- `e2e/scn-050.spec.ts`: уведомление на первом запуске и переключатель в настоящем Chromium.
