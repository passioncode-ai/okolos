# 0003. Один аудируемый узел сети, и запись делается до запроса

Принято 2026-08-04. Действует.

## Контекст

Расширение просит доступ ко всем сайтам. Обещание «мы почти ничего не
отправляем» проверить нельзя — его можно только показать.

## Решение

Наружу ходит ровно один модуль, `@okolos/net`. Каждый запрос:

1. проверяется на принадлежность к перечисленным назначениям;
2. **записывается в журнал отправок до отправки**;
3. отменяется, если запись не удалась.

Порядок именно такой. Обратный порядок означает, что неудавшаяся запись даёт
неучтённый запрос — единственное, что этот модуль обязан сделать невозможным.

## Цена

Любой новый вид запроса требует нового назначения в контракте, иначе он просто
не уйдёт.

## Чем держится

`tools/gates/bundle-scan.test.ts` ищет `fetch` в собранных артефактах и
требует, чтобы он был только в транспорте — `packages/net/src/transport.ts`.
Порядок «журнал раньше запроса» держит `packages/net/src/request.test.ts`.

Список назначений читается из контракта `packages/contracts/src/rpc.ts`, а не
переписывается: `tools/docs.test.ts` сверяет с ним и бренд-пак, и
`docs/privacy.md`. Первая версия той проверки перечисляла пять назначений, а их
было шесть, — и `password-range`, который несёт часть хеша пароля, был невидим для
проверки, написанной, чтобы его заметить.
