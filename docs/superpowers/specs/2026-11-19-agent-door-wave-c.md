# B-218, волна (в): агент делает обратимые действия Okolos через дверь Okolos Agent

**Дата:** 2026-11-19. **Строка:** B-218 в `docs/backlog.md`. **Решение:** [ADR-0022](../../adr/0022-okolos-actions-get-their-agent-door-through-okolos-agent.md),
пункт 3 «обратимые действия над своими настройками» и пункт 4 «(в)». **Опирается на** волны (а) и (б):
[wave-a](2026-11-19-agent-door-wave-a.md), [wave-b](2026-11-19-agent-door-wave-b.md).

## 1. Что сделать

Привязанный агент делает по слову человека то, что человек делает кнопкой и может отменить: убрать
сайт из доверенных, отметить находку решённой, отложить её, принять замеченное изменение расширения.
Позже в той же волне: список брендов, тихий режим, срок хранения.

## 2. Что известно

- У этих действий уже есть RPC фона (`packages/contracts/src/rpc.ts`): `trust/revoke`, `finding/resolve`,
  `finding/defer`, `extensions/trust`. Волна (в) зовёт те же функции, а не пишет свои.
- **Три из четырёх ослабляют защиту.** Агент, которого обманула страница, может отметить решённой ту
  находку, что предупреждает о ней, или принять изменение прав расширения, которое его же и обманывает.
  ADR-0022 отнёс их к обратимым, а не к воротам; цена этого решения: человек должен видеть каждое такое
  действие и отменять его одним нажатием.
- Демон знает, какой агент зовёт (`call.agent` в `apps/agent/src/door/door.ts`), а расширение пока нет:
  запрос несёт глагол и вход (`ExtensionRequest`).

## 3. Решение

### 3.1. Глаголы

| Глагол | Вход | Что делает | Ослабляет защиту |
|---|---|---|---|
| `okolos.trust.revoke` | `{ domain }` | убирает сайт из доверенных (`trust/revoke`) | нет |
| `okolos.finding.resolve` | `{ id }` | отмечает находку решённой (`finding/resolve`) | да |
| `okolos.finding.defer` | `{ id, days: 1..30 }` | откладывает находку (`finding/defer`) | да |
| `okolos.extension.accept` | `{ id }` | принимает изменение расширения (`extensions/trust`) | да |

### 3.2. Кто сделал, видно человеку (WC-1)

Демон кладёт в запрос имя и id агента (`by: { agentId, name }`), расширение пишет каждое действие в свой
журнал с ними: «Агент scout отметил решённой находку на example.com». Действие, которое ослабляет
защиту, ещё и попадает в строку «что изменилось» попапа (SCR-02), пока человек его не увидел.

### 3.3. Отмена (WC-2)

У каждой записи журнала о действии агента, ослабившем защиту, есть «Вернуть»: находка снова открыта,
изменение расширения снова не принято. Отмена человеком в журнале с его словом, не агента.

### 3.4. Что агент не может

Добавить сайт в доверенные, отключить расширение, удалить данные, снять блокировку: это ворота волны (г)
или вовсе не дверь агента (ADR-0022, пункт 3).

## 4. Требования

| ID | Требование |
|---|---|
| WC-1 | Каждое действие агента в журнале расширения с `agentId` и именем; ослабляющее видно в попапе |
| WC-2 | Ослабляющее действие отменяется одним нажатием из журнала; тест на отмену |
| WC-3 | Глагол зовёт ту же функцию фона, что кнопка; тест сверяет состояние после кнопки и после глагола |
| WC-4 | Вход проверяется в демоне и в расширении; чужой id находки или расширения: отказ без действия |
| WC-5 | Ни одного действия из класса ворот (доверить, отключить, удалить, снять блокировку) среди глаголов; тест по списку |

## 5. Финишная черта волны (в)

Четыре глагола работают через `execute` в Chromium (e2e), WC-1…WC-5 держатся тестами, журнал и попап
говорят, какой агент что сделал, «Вернуть» работает; сценарий, экраны (SCR-02, SCR-07, SCR-09, SCR-11,
SCR-16), приватность и тексты через Copylot; `pnpm gates` и CI зелёные.

## 6. План

1. Демон: `by` в `ExtensionRequest`, четыре операции по таблице, слова глаголов на странице Okolos Agent.
2. Расширение: глаголы зовут функции RPC, журнал с агентом; тест WC-3, WC-4, WC-5.
3. UX: запись журнала о действии агента и «Вернуть» (SCR-11), строка попапа (SCR-02); сценарий; Copylot.
4. e2e.
5. Вторая часть волны: бренды, тихий режим, срок хранения (найти, где их пишет страница настроек).
