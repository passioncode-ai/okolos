## Как есть и как будет

| Модуль | Как есть | Как будет |
|---|---|---|
| Расширение | работает на Windows по коду (пути загрузок режутся по обоим разделителям), но Windows нигде не обещан и не проверяется | Windows с Chrome, Edge и Firefox записан как поддерживаемая платформа; Windows-типы загрузок и опасные схемы ссылок покрыты |
| `okolos-mail` | `scan` на Windows молча выходит с 0 | `scan` работает на Windows; наблюдение за почтой остаётся только для Apple Mail (решено брифом почтового стража) |
| Инструменты разработчика | `pnpm gates`, pre-push, `pnpm package`, e2e Firefox, deploy-worker опираются на POSIX | всё это запускается на Windows; права файлов проверяются только там, где они есть |
| CI | только `ubuntu-latest` | плюс задание на `windows-latest`: сборка и unit-гейты; e2e остаются на Linux |
| Агент фида | launchd на машине с ключом подписи (ADR-0017); при пропавшей рабочей копии падает молча; снимок в репозиторий коммитит человек | сбой виден в статусе при любом исходе; снимок попадает в репозиторий PR-ом агента, без ручного шага |
| Okolos Agent (мост Б1) | только macOS, решение не записано | решение записано: Б1 только macOS, Windows отдельной фазой со строкой бэклога |

## Удаляется

Ничего из кода не удаляется, кроме, по решению SW-10, мёртвой отправки `inference/score`, если
выбран вариант «убрать» (ADR-0006).

## Швы

- Агент фида и репозиторий: снимок `feeds/phishing.json` и проверка возраста `tools/feed-age.mjs`
  (ADR-0002). SW-06 меняет только того, кто кладёт снимок, не потолок.
- Гейты и CI: SW-05 запускает на Windows те же команды, что SW-02 делает переносимыми; SW-05
  идёт после SW-01 и SW-02.

## Вопросы оператору (одним списком; без ответа действует рекомендация, помечена «принято»)

1. **Поддержка Windows.** Рекомендация: расширение, `okolos-mail scan` и инструменты разработчика
   поддерживают Windows; Okolos Agent в Б1 только macOS. **Принято по умолчанию.**
2. **Снимок фида.** Рекомендация: агент фида сам открывает или обновляет PR со снимком, когда
   закоммиченный снимок старше 7 дней; агенты сливают его по зелёным проверкам. **Принято по
   умолчанию** для построения; первое слияние такого PR покажу.
3. **Листинг Edge Add-ons.** Публикация необратима и наружу: не делается без вашего отдельного
   «да». Записывается в B-137.
4. **CI на Windows на каждый push и PR.** Решено источником: `AGENTS.md` (публичный репозиторий,
   CI на push и PR). Не спрашивается.
5. **N-007 и N-013 (B-157).** Ваше «давай все доделаем» принято как просьба продолжить круги.
