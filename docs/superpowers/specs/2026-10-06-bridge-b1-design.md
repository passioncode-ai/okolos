# Спека — Okolos Bridge, фаза Б1: мост на чтение

Стадия 3 пайплайна для следующего прогона. Дата 2026-10-06, основа `a4c4863` плюс ветка
`bridge/b0`.

**Источники:**
- решения: ADR-0018, ADR-0019, стратегия §8.6–8.7;
- сценарии: SCN-044, SCN-045, SCN-048 (`docs/ux/scenarios.md`);
- замеры: [evidence/2026-10-06-b0-agent-window.md](../evidence/2026-10-06-b0-agent-window.md);
- архитектура: отчёт `okolos/2026-10-05-agent-browser-bridge` (база знаний продукта, вне этого
  репозитория).

**Что Б1 даёт человеку:** его агенты читают страницы за его логинами через одну локальную дверь.
Что они читают, очищено от скрытых инструкций. Секретов они не видят, фокус не забирают. Вместо
браузерного MCP-сервера в каждой сессии работает один демон. **Действий в Б1 нет** — это Б2.

Расширение Okolos Bridge (дверь-расширение, native host) — **Б2**. В Б1 работает только окно
агента: замер показал, что оно обходится без инфобара и без `chrome.debugger`, а значит без
ревью магазина. Первая ценность приходит без недель ревью.

**Walking skeleton.** Агент вызывает `session.open` → демон запускает окно агента → `open`
локальной фикстуры → `snapshot` со следом одной находки из корпуса → `close`. Путь проходит
через e2e на настоящем Chrome до появления второго глагола.

## 2. Контракты (K0)

### 2.1 Задача

```ts
interface TaskScope {
  goal: string                 // цель человека, словами агента; читает сторож дрейфа (Б3)
  origins: { read: string[]; write: string[] }   // точные origin; write ⊆ read
  verbs: BridgeVerb[]          // подмножество закрытого набора
  ttlSeconds: number           // ≤ 3600
  stepBudget: number           // ≤ 500 вызовов
  profile: 'agent' | 'disposable'   // agent — с логинами человека; disposable — без логинов
}
```

### 2.2 Глаголы Б1 (только чтение)

| Глагол | Вход | Выход |
|---|---|---|
| `session.open` | `TaskScope` | `{ sessionId, windowId }` |
| `open` | `{ url }` из `origins.read`, или `{ ref }` ссылки на текущей странице | `{ url: <фактический после навигации> }` |
| `snapshot` | `{ ref?: string, cursor?: string, maxBytes?: number }` | `{ text, refs, verdict, cursor?: string, partial: boolean }` |
| `read` | `{ ref?: string, maxBytes?: number }` | `{ text, boundary: { nonce, origin } }` |
| `get` | `{ what: 'url' \| 'title' \| 'text' \| 'count', ref?: string }` | значение |
| `waitFor` | `{ ms } \| { text } \| { url }` | — |
| `screenshot` | `{ ref?: string }` | изображение частями |
| `close` | — | окно и процессы задачи закрыты |
| `hygiene.census` | — | перепись (K5) |

Набор совпадает с драйвером исполнителя сценариев, который согласовал его 2026-10-05: закрытые
глаголы, навигация по allowlist или `ref`, фактический URL после навигации, своё окно на задачу.

### 2.3 Конверт и отказы

```ts
type BridgeResult<T> = { success: true; data: T } | { success: false; error: { code: BridgeRefusal; message: string; retryable: boolean } }
type BridgeRefusal =
  | 'not_paired' | 'origin_not_in_task' | 'verb_not_in_task' | 'budget_exhausted' | 'task_expired'
  | 'tab_gone' | 'busy' | 'in_use_by_person' | 'browser_offline' | 'blocked_by_shield' | 'internal'
```

Отказ политики — `retryable: false`. Повтор после отказа списывается с бюджета задачи.

## 3. Правила, которые держит код Б1

| Правило | Где | Чем проверяется |
|---|---|---|
| Дверь — Streamable HTTP только на `127.0.0.1`. Каждый запрос несёт ключ привязки. `Host` и `Origin` сверяются со списком. Клиент не одобряется автоматически за то, что он локальный | K3 | тесты: без ключа, чужой `Origin`, DNS-rebinding `Host` → `not_paired`, запись в журнал |
| Привязка — человеком, со сверкой кода. Ключ хранится в связке ключей macOS. Отзыв закрывает задачи агента | K3 | e2e SCN-044 |
| Окно агента: `--no-startup-window`, окна задач через `Target.createTarget {newWindow: true, background: true}`, без `--enable-automation` | K4 | e2e: фронтальное приложение не меняется; высота рамки без инфобара (метод из спайка) |
| Одна задача — одно окно с активной вкладкой. Фоновые вкладки для задач не используются | K4 | e2e: клик в задаче — `isTrusted: true` |
| Снимок проходит движок до выдачи. Скрытое вырезано, находка приложена, значения полей `password`, `cc-*` и OTP не выдаются | K2 | корпус `corpora/injections`: ни один позитив в выдаче; fuzz-тест: значения, которые тест сам ввёл, не встречаются в ответах |
| Снимок выдаётся частями: `maxBytes` по умолчанию 32 КБ, курсор для продолжения, `ref` для поддерева | K2 | Википедия (10,5 МБ сырого, по замеру Б0) выдаётся страницами ≤ 32 КБ, и сумма страниц покрывает всё сжатое дерево |
| Фрагмент URL (`#…`) агенту не отдаётся | K2 | тест на URL с фрагментом |
| Каждый ответ агенту записывается в журнал **до** отправки. Отказ записи — отказ ответа (ADR-0019) | K3 | тест: журнал недоступен → `internal`, ответа нет |
| Демон ничего не отправляет в сеть, кроме того, что уже разрешено `@okolos/net` | K3 | `packages/net/src/destinations.test.ts` и гейт бандла |
| Процессы окна агента — дерево демона. При остановке демона и при `close` они завершаются: SIGTERM, потом SIGKILL группе | K4 | тест: после `kill -9` демона и перезапуска сирот окна нет |
| Перепись (K5) только читает. Служба ОС, живая сессия, браузер человека помечаются как «не трогать», с причиной | K5 | тест на снимке `ps`/`launchctl` из фикстуры (охранные правила C3 отчёта) |

## 4. Чего Б1 не делает

- **Действий нет:** `click`, `fill`, `type`, `press`, `select`, загрузок и выгрузок нет. Это Б2
  вместе с таксономией и панелью подтверждений.
- **Нет расширения Okolos Bridge и native host** — Б2.
- **Уборщик только переписывает:** завершение процессов — Б3. Исключение — собственные процессы
  окна агента, их демон закрывает всегда.
- **Нет Firefox и Safari** — Б5.

## 5. Риски, видимые сейчас

| Риск | Гашение |
|---|---|
| Chrome закроет pipe-CDP на не-дефолтном профиле, как в 136 закрыл порт на дефолтном | дверь-расширение (Б2) остаётся вторым путём; замер повторяется на каждом мажоре (B-143) |
| Политика предприятия запрещает параметры командной строки | `browser_offline` с причиной; замер B-144 до обещаний корпоративным пользователям |
| Логины в профиле агента: человеку нужно один раз войти в нужные сервисы | так задумано: импорт cookies из основного профиля не делается (App-Bound Encryption); вход — шаг человека в SCN-047 |
| Демон под launchd — ещё один долгоживущий процесс | один демон вместо N серверов на сессию: на машине 2026-10-05 это 63 процесса и около 2 ГБ |
