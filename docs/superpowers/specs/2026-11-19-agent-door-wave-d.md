# B-218, волна (г): агент просит ворота, человек решает в Okolos

**Дата:** 2026-11-19. **Строка:** B-218 в `docs/backlog.md`. **Решение:** [ADR-0022](../../adr/0022-okolos-actions-get-their-agent-door-through-okolos-agent.md),
пункт 3 «ворота и необратимое» и пункт 4 «(г)». **Опирается на** волны (а), (б), (в):
[wave-a](2026-11-19-agent-door-wave-a.md), [wave-b](2026-11-19-agent-door-wave-b.md), [wave-c](2026-11-19-agent-door-wave-c.md).

## 1. Что сделать

Агент, которого остановили ворота Okolos (блокировка сайта SCR-05, похожий адрес SCR-19, проверка
действия агента SCR-06), может **попросить** их снять. Снимает только человек, нажатием на поверхности
Okolos, которую агент не подделает. Удаление всех данных агент просит через `fabric_effect_request`,
не через Okolos.

## 2. Что известно

- Ворота держат того самого агента, который просит. Дверь, которая снимает ворота по просьбе агента
  без человека, снимает их руками того, кого они держат (ADR-0022, контекст).
- **Текст агента для человека тоже инъекция.** Причина, которую агент напишет («это мой сайт, разреши»),
  прочтёт человек; страница, обманувшая агента, напишет её за него. Значит, запрос несёт только вид ворот
  и хост, а не слова агента.
- Поверхности Okolos в закрытом корне тени, страница их не читает и не нажимает (ADR-0001).

## 3. Решение

### 3.1. Глаголы

| Глагол | Вход | Ответ |
|---|---|---|
| `okolos.request.lift` | `{ gate: 'block' \| 'lookalike' \| 'agent-action', host }` | `{ requestId, state: 'waiting' }` |
| `okolos.request.state` | `{ requestId }` | `{ state: 'waiting' \| 'allowed' \| 'declined' \| 'expired' }` |

Запрос живёт 10 минут. На хост и вид ворот один ждущий запрос: повтор отвечает тем же `requestId`.

### 3.2. Где решает человек (WD-1)

Попап (SCR-02) и страница ворот, если она открыта на этом хосте, показывают одну строку: «Агент scout
просит снять блокировку для example.com», с кнопками «Разрешить один раз» и «Отказать». Строка собрана
из имени агента (его проверил демон при привязке), вида ворот словами каталога и хоста; ни одного слова
от агента. «Разрешить один раз» делает то же, что одноимённая кнопка ворот для этого хоста, один раз.

### 3.3. Что не просится

«Это неверно» и восстановление скрытого текста (SCR-03, SCR-04): человек видит текст сам, просьба агента
показать ему спрятанное противоречит смыслу. Удаление всех данных и очистка хранилища: через
`fabric_effect_request`, решение оператора в Fabric, нажатие человека в Okolos.

## 4. Требования

| ID | Требование |
|---|---|
| WD-1 | Снятие ворот только нажатием человека на поверхности Okolos; ни один глагол не снимает ворота сам |
| WD-2 | В строке запроса нет текста агента: только имя, вид ворот словами каталога, хост; тест с посаженной инструкцией в поле, которого нет в схеме |
| WD-3 | Запрос истекает через 10 минут; один ждущий на хост и вид |
| WD-4 | Каждый запрос, разрешение и отказ в журнале с именем агента |

## 5. Финишная черта волны (г)

Два глагола через `execute`, строка запроса в попапе и на странице ворот, «Разрешить один раз» и
«Отказать» работают, WD-1…WD-4 держатся тестами, e2e в Chromium, сценарий, экраны и тексты через Copylot,
`pnpm gates` и CI зелёные.

## 6. План

1. Контракт и демон: два глагола, схема без свободного текста.
2. Расширение: хранилище запросов с истечением, ответ состояния, журнал.
3. UX: строка запроса в попапе (SCR-02) и на странице ворот (SCR-05, SCR-06, SCR-19); Copylot.
4. e2e.

Шаг 1 сделан 2026-11-19, ветка `waves/b218-wave-d`: два глагола в контракте и демоне, схема без поля для
текста агента (тест WD-2 в `apps/agent/src/verbs/verbs.test.ts`). Найдено при шаге 2: «Всё равно
продолжить» на блокировке (SCR-05) кладёт сайт в доверенные насовсем (`allowBlocked` в
`apps/extension/src/background/index.ts`), а «Разрешить один раз» у ворот действия агента (SCR-06)
привязано к ждущему действию на странице (`gate/decision`). Поэтому шаг 2 идёт по видам: сначала
`block` и `lookalike` (снятие по хосту), затем `agent-action`, для которого запрос должен знать ждущее
действие (О-8).

Шаг 2 и UX шага 3 сделаны 2026-11-19 для `block` и `lookalike`: `apps/extension/src/background/agent-requests.ts`
(просьба живёт 10 минут в `storage.local`, одна ждущая на хост и вид, журнал с именем агента), строка
просьбы в попапе (SCR-02, `[data-role=agent-requests]`) с «Разрешить» и «Отказать», RPC `agent/decide` только
со страниц расширения; «Разрешить» делает то же, что «Всё равно продолжить» (сайт в доверенных, правила
пересобраны). `agent-action` отвечает агенту, что эти ворота снимает только нажатие на странице (О-8).
Осталось: строка просьбы на самой странице ворот (SCR-05, SCR-19), e2e.

## 7. Открытые вопросы

- **О-8. Ворота действия агента.** Запрос `agent-action` имеет смысл, только пока действие ждёт на
  странице; связать запрос с ним (id ждущего решения) или отвечать агенту, что эти ворота снимает только
  нажатие на самой странице.


- **О-7. Уведомление.** Сказать ли человеку о запросе, пока попап закрыт (значок расширения с числом,
  как у находок); решается с UX волны.
