# B-218, волна (б): агент читает Okolos через дверь Okolos Agent

**Дата:** 2026-11-19. **Строка:** B-218 в `docs/backlog.md`. **Решение:** [ADR-0022](../../adr/0022-okolos-actions-get-their-agent-door-through-okolos-agent.md),
пункт 4 «(б) чтение и выгрузка». **Опирается на** волну (а):
[2026-11-19-agent-door-wave-a.md](2026-11-19-agent-door-wave-a.md) (привязка кодом, будильник `okolos:agent`,
маршрут `/extension/*`, операция `okolos.ping`).

## 1. Что сделать

Привязанный к Okolos Agent агент читает то, что Okolos знает, теми же операциями `execute`, что
`okolos.ping`: очередь находок, вердикт по адресу, журнал, журнал отправок, найденные изменения
расширений. Человек ничего не нажимает: привязка Okolos (волна (а)) и доступ агента (Б1) уже его
решения.

## 2. Что известно

- Ответ уходит тем же путём, что `okolos.ping`: фон берёт запрос на пробуждении и отвечает
  `POST /extension/answer`, каждый запрос в журнале отправок под целью `agent-door`
  (`apps/extension/src/background/agent-door.ts`).
- **Находки Okolos содержат текст атакующего.** Очередь хранит фрагмент скрытой инструкции
  (`verdict.evidence[].snippet`), журнал хранит объяснения с аргументами. Отдать фрагмент агенту
  значит передать ему ту самую инструкцию, от которой Okolos защищает: агент прочтёт её как текст
  задачи.
- Ответ демону ограничен 64 КиБ (`MAX_EXTENSION_BODY` в `apps/agent/src/extension/route.ts`).

## 3. Решение

### 3.1. Глаголы волны (б)

| Глагол | Вход | Ответ |
|---|---|---|
| `okolos.queue` | `{ limit?: 1..50 }` | открытые находки: id, категория, тяжесть, хост, когда найдена |
| `okolos.verdict` | `{ url }` (http или https) | в списке блокировки ли хост (имя списка, дата записи), сколько открытых находок на хосте по категориям, доверенный ли хост |
| `okolos.journal` | `{ limit?: 1..50 }` | последние записи журнала: вид, итог, когда, хост |
| `okolos.audit` | `{ limit?: 1..50 }` | журнал отправок: когда, куда, зачем, форма полезной нагрузки, итог (то, что показывает SCR-10) |
| `okolos.extensions` | `{}` | замеченные изменения расширений: имя, id, что изменилось, когда |

Выгрузка всех данных (SCR-12) в волну (б) не входит: в ней фрагменты страниц, и её смысл в том,
чтобы человек унёс файл. Она уходит в класс ворот волны (г) по запросу человека.

### 3.2. Через дверь не идёт содержимое страниц (WB-1)

Ни фрагмент, ни адрес страницы целиком, ни текст объяснения с аргументами. Хост (`example.com`) идёт:
без него ответ бесполезен, а хост и так виден агенту, который ходит по сайтам. Ответ строится из
полей-перечислений и чисел, а не из строк, которые пришли со страницы; тест сверяет каждый ответ с
посаженной в хранилище инструкцией и требует, чтобы её не было ни в одном байте.

### 3.3. Журнал отправок

Ответ агенту пишется в журнал отправок до отправки, как любой запрос. Форма полезной нагрузки называет
глагол: `agent-door:answer:okolos.queue`. В самоаудите (SCR-10) ответы агентам не сворачиваются в
фоновые строки: пробуждение сделал Okolos, а вопрос задал агент, и человек должен видеть каждый
ответ отдельно (`madeOnItsOwn` не трогает `agent-door:answer:*`, кроме ответа на `okolos.ping`).

### 3.4. Что видит человек

Блок «Okolos Agent» в «Ваших данных» (SCR-12) называет, что агенты могут прочесть, одной строкой, и
ведёт к журналу отправок. Страница приватности и `docs/brand/facts.md` называют ответы агентам и то,
что в них нет.

## 4. Требования

| ID | Требование |
|---|---|
| WB-1 | Ни один ответ не несёт фрагмента страницы, адреса страницы целиком или объяснения с аргументами; тест с посаженной инструкцией |
| WB-2 | Каждый глагол отвечает только привязанному Okolos и только через `execute` двери; без привязки `extension_not_connected` |
| WB-3 | Каждый ответ в журнале отправок до отправки, форма называет глагол |
| WB-4 | Ответ не больше 64 КиБ: `limit` до 50 и короткие поля; больше не бывает и проверено тестом |
| WB-5 | Вход проверяется схемой в демоне и в расширении; неверный вход: `bad_call` |
| WB-6 | `okolos.verdict` принимает только http и https и отвечает по хосту |

## 5. Финишная черта волны (б)

Пять глаголов отвечают агенту через `execute` в Chromium (e2e, как `e2e/scn-054.spec.ts`); WB-1…WB-6
держатся тестами; SCR-12, SCN-054 (или новый сценарий), приватность и факты названы; `pnpm gates` и CI
зелёные.

## 6. План

1. Контракт: пять глаголов в `packages/contracts/src/bridge.ts` (вход, ответ), операции демона в
   `apps/agent/src/verbs/verbs.ts` по таблице, слова глаголов на странице Okolos Agent.
2. Расширение: ответы по таблице в `agent-door.ts` из хранилища, без строк со страницы; тест WB-1.
3. UX и тексты: строка в блоке SCR-12, приватность, факты, сценарий; Copylot.
4. e2e: пять глаголов через `execute` в Chromium.

## 7. Открытые вопросы

- **О-5. Выгрузка для агента.** Нужна ли агенту выгрузка без фрагментов как отдельный глагол, или
  хватает пяти; решается, когда появится просьба агента.
