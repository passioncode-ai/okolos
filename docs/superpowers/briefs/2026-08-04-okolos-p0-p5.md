# Pipeline brief — Okolos P0–P5 + public domain status

- **Дата:** 2026-08-04
- **Стадия:** 0 (intake) — бриф на замок
- **Модель прогона:** Opus 5 (подтверждено на preflight)

## 1. Задача

MV3-расширение (Chrome/Edge/Firefox) + тонкий Cloudflare Worker. Безопасность
браузинга в эпоху AI-агентов: детект и очистка скрытых инструкций для
AI-агентов, базовый анти-скам (ссылки, страницы, загрузки), утёкшие пароли и
данные, контроль расширений, дружелюбный ассистент, публичная страница статуса
домена с апелляциями. Опенсорс AGPL-3.0, английский UI, локальность
проверяема.

**Развилка закрыта 2026-08-08 (human step 4).** Политика: проект несёт только
веса, которые можно перераспространять и производные от которых разрешены, без
принятия пользователем чужих условий — публичный AGPL-репозиторий не может
согласиться на acceptable-use за своего пользователя. Семейство Llama, включая
`Llama-Prompt-Guard-2-22M`, исключено этим правилом.

Измерения показали, что лицензия и размер здесь — **один вопрос**: единственный
ungated Apache-2.0 артефакт весит 738 563 308 байт, а малые варианты того же
семейства отдают 401 без авторизации. Apache-2.0 разрешает производные при
сохранении атрибуции, поэтому открытый путь — собственная INT8-квантизация:
сначала измерить размер и качество, потом решать. Если не сойдётся с бюджетом
REQ-09, третья ступень не выпускается, и честная деградация для этого уже
построена и покрыта тестами.

Решение, доказательства и обязательства Apache-2.0 §4 — в
[../../licences.md](../../licences.md). Дескриптор модели указывает на
`pending-quantisation.onnx` с нулевым дайджестом: артефакта ещё нет, и врать
про него нечего.
